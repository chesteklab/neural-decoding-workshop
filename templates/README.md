# Templates

This folder contains reusable forms and templates for workshop registration and feedback collection.

##  Folder Structure

```
templates/
├── Feedback Form 2025.pdf   # This is the post-workshop feedback form, sent at workshop conclusion
├── Sign-Up Application 2025.pdf   # Application with pre-workshop information
├── Attendance Confirmation 2025.pdf   # Sent before the workshop to confirm attendance for planning and team formation
└── README.md   # This file
```
