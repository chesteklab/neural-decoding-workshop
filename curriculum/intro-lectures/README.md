# Introductory Lectures

This folder contains foundational materials that should be presented at the beginning of the workshop. These lectures set the stage for the entire workshop by introducing key concepts, providing context, and orienting participants.

## Contents

```
intro-lectures/
├── neural-decoding-introduction.ipynb    # Main introduction to neural decoding
├── dataset-introduction.pdf              # Overview of all available datasets
└── README.md                            # This file
```

## Purpose

These introductory materials serve to:
- Establish common vocabulary and understanding
- Motivate the study of neural decoding
- Preview workshop structure and goals
- Introduce available datasets and projects

## Materials

### 1. Neural Decoding Introduction

**File**: `neural-decoding-introduction.ipynb`

**Format**: Jupyter notebook 

**Duration**: 45-60 minutes

**Content Overview**:
- What is neural decoding?
- Why study brain-computer interfaces?
- Historical context and major milestones
- Basic neuroscience concepts (neurons, action potentials, recording methods)
- Overview of the decoding problem
- Workshop goals and structure

---

### 2. Dataset Introduction

**File**: `dataset-introduction.pdf`

**Format**: PDF presentation

**Duration**: 15-30 minutes

**Content Overview**:
- Overview of all four datasets (MC-Maze, Monkey Fingers, Willet Speech, Zebra Finch)
- Experimental paradigms for each
- Types of questions each dataset can answer
- Guidance on choosing a dataset
