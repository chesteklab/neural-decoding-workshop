# Admin

This folder contains all administrative materials needed to plan, organize, and execute this workshop. 

## Folder Structure

```
admin/
├── judging/       # Materials for evaluating participant projects
├── outreach/      # Promotional materials and example groups to contact
├── planning/      # Example schedules, task lists, and team coordination
└── README.md     # This file
```

## Quick Start Guide for Organizers

### x Months Before Workshop
1. **Planning Phase** (`planning/`)
   - Review example schedules and adapt to your timeline
   - Develop task list and sign-up sheet

2. **Outreach Phase** (`outreach/`)
   - Customize flyers with your event details
   - Send sign-up forms to contact list

### 1-3 Months Before
3. **Registration Setup** (`../templates/`)
   - Set up registration forms
   - Collect participant information
   - Send confirmation emails with prep materials

4. **Content Preparation** (`../curriculum/`)
   - Test all notebooks and datasets
   - Prepare any custom materials
   - Arrange guest speakers if applicable

### 1-2 Weeks Before
5. **Final Logistics** (`planning/`)
   - Finalize daily schedule
   - Confirm room bookings and meal catering
   - Send reminder emails with logistics

### During Workshop
6. **Project Management** (`judging/`)
   - If running a competition, introduce judging criteria early
   - Have participants form teams based on skill levels

### After Workshop
7. **Feedback and Follow-up** (`../templates/`)
   - Collect participant feedback
   - Document lessons learned for next iteration

**Scoring Sheet** (`judging/Example Scoring Sheet.xlsx`)

###  Judging Categories

1. **Scientific Merit** (30-40%)
   - Question clarity and significance
   - Approach appropriateness
   - Understanding of methods

2. **Technical Implementation** (30-40%)
   - Code quality and organization
   - Proper use of techniques learned
   - Handling of edge cases

3. **Communication** (20-30%)
   - Presentation clarity
   - Visualization quality
   - Ability to explain results

4. **Creativity/Innovation** (10-20%)
   - Novel approaches
   - Going beyond basic requirements
   - Interesting insights

### Running Project Competitions

**Day 1**: Introduce projects and judging criteria
- Form teams (2-4 people recommended)
- Have teams choose datasets
- Encourage defining clear questions

**Mid-Workshop**: Check-in with teams
- Host mini-workshops to supplement learning
- Check-ins with grad students about project scope
- Provide guidance if stuck

**Final Day**: Presentations and judging
- 10-15 minutes per team (including Q&A)
- Have 3-5 judges score independently
- Deliberate and announce winners

### Judge Recruitment

Ideal judges:
- Faculty or postdocs in neuroscience/ML
- Industry professionals in BCI or data science
- Advanced graduate students 

Provide judges with:
- Scoring rubric in advance
- Individual scoring sheets
- Brief orientation on workshop content

## Resources Needed

### Time Commitment
- Preparation: 20-30 hours 3-6 months ahead of workshop
- Day-of coordination: Full time during workshop
- TAs: Workshop duration + 5-10 hours prep

### Space Requirements
- Main room for 20-50 people
- Projector and screen
- Power outlets at each table
- Breakout spaces (optional but recommended)
