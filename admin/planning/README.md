## 📅 Schedule Planning

**File**: `Example Schedule.xlsx`

### What's Included

A detailed timeline covering:
- **Daily schedules** with session times
- **Session titles and descriptions**
- **Instructor assignments**
- **Room locations** (if multiple spaces)
- **Break times** and meal planning
- **Setup and cleanup time**
- **Buffer time** for running over

### Creating Your Schedule

**Step 1: Determine Overall Structure**
```
Half-day (4 hours):
  - Introduction (30-45 min)
  - One mini-workshop (2 hours)
  - Hands-on work (1-1.5 hours)

Full-day (8 hours):
  - Morning: Introductions + dataset exploration (3-4 hours)
  - Afternoon: Mini-workshops + project work (3-4 hours)

Multi-day (2-5 days):
  - Day 1: Foundations
  - Day 2-3: Techniques and project work
  - Day 4-5: Advanced topics + presentations
```

**Step 2: Block Out Fixed Items**
- Opening and welcome (Day 1 start)
- Meals and breaks
- Final presentations (last afternoon)
- Project work time (must have!)

**Step 3: Schedule Content**
- Introductory lectures first
- Progressive complexity (linear → nonlinear ML)
- Essential skills early (data viz, basic stats)
- Advanced topics mid-to-late workshop
- Leave flexibility for participant questions

**Step 4: Add Logistics**
- Check-in time (15-30 min before start)
- Setup time before each day
- Cleanup time at end
- Transition time between sessions (5-10 min)

### Scheduling Best Practices

**Timing**:
- ✅ Schedule cognitively demanding content in mornings
- ✅ Include 10-15 min break every 90 minutes
- ✅ Provide 60 min lunch break
- ✅ End by 5:00 PM to avoid fatigue
- ✅ Build in 10-15% buffer time
- ⚠️ Don't schedule back-to-back intense sessions
- ⚠️ Don't forget transition time between activities

**Content Flow**:
- ✅ Start with motivation and big picture
- ✅ Move from concrete examples to abstractions
- ✅ Alternate between lecture and hands-on
- ✅ Build incrementally
- ⚠️ Don't jump skill levels too quickly
- ⚠️ Don't save essential content for last day

**Flexibility**:
- ✅ Plan what to cut if running behind
- ✅ Have optional advanced material if ahead
- ✅ Allow time for questions and discussion
- ✅ Schedule project work for participant-driven exploration

## ✅ Task Management

**File**: `Example Task Sign Up.xlsx`

### Purpose

Comprehensive task list ensuring all details are covered and clearly assigned. Prevents "I thought you were doing that!" moments.

### Typical Task Categories

**Pre-Workshop (Weeks/Months Before)**
- [ ] Secure venue and equipment
- [ ] Create and distribute promotional materials
- [ ] Set up registration system
- [ ] Order food/refreshments
- [ ] Confirm instructor availability
- [ ] Prepare/test all technical materials
- [ ] Purchase prizes (if applicable)
- [ ] Print materials (name tags, schedules, certificates)

**Week Before**
- [ ] Send reminder emails to participants
- [ ] Confirm final attendance numbers
- [ ] Update catering order
- [ ] Test all equipment in venue
- [ ] Prepare participant packets
- [ ] Create seating chart (if assigned)
- [ ] Brief TAs and instructors
- [ ] Prepare emergency contact list

**Day Of (Each Day)**
- [ ] Arrive early for setup
- [ ] Test projector and laptops
- [ ] Check WiFi access
- [ ] Set up check-in desk
- [ ] Arrange name tags
- [ ] Post directional signs
- [ ] Set up coffee/snacks
- [ ] Confirm meal delivery times
- [ ] Have TAs monitor chat/questions
- [ ] Take photos (with permission)
- [ ] Troubleshoot tech issues

**Post-Workshop**
- [ ] Send thank you emails
- [ ] Distribute feedback forms
- [ ] Share materials and resources
- [ ] Process and analyze feedback
- [ ] Send certificates
- [ ] Return borrowed equipment
- [ ] Reconcile budget
- [ ] Document lessons learned
- [ ] Archive materials

### Using the Task Spreadsheet

**Columns to include**:
- Task description
- Responsible person
- Deadline
- Status (Not started, In progress, Complete)
- Priority (High, Medium, Low)
- Dependencies (what must happen first)
- Notes

**Update regularly**:
- Weekly team check-ins
- Mark completed tasks immediately
- Flag blockers or delays
- Adjust assignments as needed

**Example entries**:
```
Task: Create promotional flyer
Assigned: Sarah
Deadline: Sept 1
Status: In Progress
Priority: High
Dependencies: Finalize dates and venue
Notes: Using template from last year

Task: Order pizza for Day 2 lunch  
Assigned: Mike
Deadline: Nov 20
Status: Not started
Priority: Medium
Dependencies: Final headcount
Notes: Check dietary restrictions from registration forms
```

## 🚨 Common Planning Pitfalls and Solutions

### Pitfall: Underestimating Setup Time
**Solution**: Arrive 1-2 hours early on Day 1, 30-60 min on subsequent days. Assign specific setup tasks.

### Pitfall: Overambitious Schedule
**Solution**: Plan for 80% of ideal content. Build in buffer time. Identify what can be cut.

### Pitfall: Poor Task Documentation
**Solution**: Use shared spreadsheet updated in real-time. Review weekly. Clearly assign owners.

### Pitfall: Last-Minute Surprises
**Solution**: Do site visit 1-2 weeks before. Test all equipment. Have backup plans.

### Pitfall: Unclear Roles
**Solution**: Write down responsibilities for each person. Review together. Overlap is okay, gaps are not.

### Pitfall: Forgetting Small Details
**Solution**: Use checklists. Have experienced organizer review plans. Learn from past workshops.

### Pitfall: Communication Breakdown
**Solution**: Regular team meetings. Shared communication channels (Slack, email list). Clear points of contact.
