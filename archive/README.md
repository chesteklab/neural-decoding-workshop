# Archive

This folder contains historical materials from previous neural decoding workshops (2023-2025). These materials provide valuable context, show the evolution of the workshop, and serve as references for future iterations.

# Contents
2023 - Contains the least materials (first year running the workshop), but contains code and schedule. We had not originally planned on doing mini-workshops, so the ones we did run this year were improvised/all done on markerboard. Many of the materials created for this first workshop are what have been iterated on in future years.

2024 - Contains more materials, including first iterations of mini-workshops. This one was hosted at Michigan. More contents here because organization was more centralized. Also includes task signup sheets, blitz talks, some datasets.

2025 - The most recent iteration of the workshop. Should overlap relatively heavily with 2024.
